# Shape Packing Solver

一个基于 Python 的应用程序，用于解决二维不规则形状的打包问题。它提供了命令行界面（CLI）和图形用户界面（GUI）两种方式，旨在将一组给定的形状打包到一个容器中，并最大化空间利用率。

打包好的`.exe`文件下载地址：[https://github.com/entishl/nkrbehgamehelper/releases]
在这里是用于nikke 生化危机联动小游戏/方舟游侠活动小游戏的武器装箱求解。
也可用于其它类似游戏。
需要自定义形状修改`shapes.json` 文件即可，或者在gui的形状管理中新增、修改、删除形状。

该求解器的核心是基于谷歌的 **OR-Tools (CP-SAT)**，一个强大的约束规划求解器。

## 功能特性

- **双重接口**: 既可用作脚本化的命令行工具，也可用作交互式的用户友好图形界面。
- **可定制的容器**: GUI 允许用户在 9x9 的网格上自定义容器的形状。
- **可定制的形状**: 可以自定义形状，支持 90 度旋转，不支持镜像。
- **形状旋转**: 求解器会自动尝试每个形状的 0°、90°、180°、270° 朝向，并去重对称形状的重复朝向。
- **基于约束的求解**: 利用 CP-SAT 求解器处理复杂的打包约束，包括非重叠规则。
- **形状分解**: 自动将不规则形状分解为一组矩形，以便于求解器处理。
- **交互式可视化**: GUI 提供了最终打包布局的实时可视化，显示的是求解器选中的实际旋转朝向。
- **灵活的控制**: 用户可以指定形状数量，为求解器设置时间限制，并“锁定”某些形状以确保它们被包含在解决方案中。

## 系统要求

- Python 3.12
- Tkinter (通常随 Python 一起安装)
- Google OR-Tools

您可以使用 pip 安装所需的库：

```bash
pip install ortools
```

## 如何使用

### 1. GUI 模式

要运行图形界面，请执行 `gui.py` 脚本：

```bash
python gui.py
```

**界面指南:**

1. **容器形状**: 在左侧的 9x9 网格中单击单元格，以定义可用于打包的区域。白色单元格可用，黑色单元格被阻挡。
2. **形状数量**: 使用输入字段和箭头按钮指定要打包的每种形状的数量。
3. **锁定形状**: 单击形状旁边的锁形图标 (🔒) 以强制求解器将该形状包含在解决方案中。
4. **允许旋转**: 取消勾选该选项，则形状不能旋转。
5. **自定义形状**: 可在形状管理中新增、修改、删除形状。
6. **时间限制**: 为计算设置一个时间限制（以秒为单位）。
7. **计算**: 按下“Calculate”按钮开始打包过程。结果将显示在右侧的输出面板中。每个形状会自动考虑可旋转朝向，无需手动输入旋转角度。

### 2. 命令行模式

要使用命令行界面，请使用所需参数运行 `main.py` 脚本。

```bash
python main.py --shape_counts "square=2,T=1" --board_size "10,10"
```

**参数:**

- `--shape_counts` (必需): 一个逗号分隔的字符串，指定要打包的每种形状的名称和数量。例如: `'square=2,T=1'`
- `--board_size` (可选): 矩形板的尺寸。默认: `'10,10'`。
- `--shapes_file` (可选): 包含形状定义的 JSON 文件的路径。默认: `shapes.json`。
- `--no_rotation` (可选): 禁用形状旋转。指定该参数后，形状只能以默认方向（0°）放置。

命令行结果会输出每个已放置形状的位置和最终选中的旋转角度。

## 技术实现

该问题被建模为一个**约束规划**问题。

1. **旋转朝向生成**: 每个形状会生成 0°、90°、180°、270° 四个候选朝向，并规范化到左上角 `(0, 0)`。如果某些朝向在形状对称时完全相同，会自动去重，减少搜索空间。
2. **位置预过滤（Valid Position Cache）**: 对每个唯一朝向，预先计算并缓存其在棋盘上的合法摆放位置（所有占用的格子都必须在棋盘的允许单元格范围内），从而减小变量规模。
3. **CP-SAT 模型**:
    - **决策变量**:
      - 每个形状关联一个布尔变量 `is_used` 表示是否放置该形状。
      - 每个合法朝向关联一个布尔变量 `orientation_is_used`。
      - 朝向下的每个合法位置关联一个布尔放置变量 `b_pos`。
    - **放置约束**:
      - 确保每个形状最多选择一个朝向，且当且仅当形状被使用时，其对应的某一个朝向和位置变量被设为真。
    - **不重叠约束**:
      - 使用基于布尔网格的排他约束（`AddAtMostOne`）。每个允许单元格收集所有能覆盖它的摆法布尔变量 `b_pos`，要求每个单元格最多只能被一个选中的摆法覆盖，从而确保形状不重叠。
    - **对称性破坏**:
      - 对中心对称的棋盘，限制面积最大的锚点形状仅能放置在棋盘的半边，安全裁剪一半的搜索空间。
      - 对同名重复形状进行排序约束，避免等价状态的冗余搜索。
4. **目标**: 模型的目标是**最大化**已放置形状的**总面积** (`sum(shape.area * is_used)`)。
5. **求解器**: CP-SAT 求解器探索解空间，以找到一个满足所有约束同时最大化目标函数的可行或最优的形状排列。使用时间限制来确保求解器在合理的时间内返回一个好的解决方案。
